# IngeTrazo Node Editor — Dependencies

# This plugin is 100% self-contained and requires NO external package installation.
#
# ─────────────────────────────────────────────────────────────

#   polyskel.py             Alternative straight-skeleton implementation (fallback)
#
# ─────────────────────────────────────────────────────────────
# ZERO MANDATORY DEPENDENCIES
