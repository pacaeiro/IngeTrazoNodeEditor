# IngeTrazo Node Editor — External Dependencies
#
# IngeTrazo ships with its own internal Python interpreter.
# This plugin vendors pure-Python libraries directly in the package folder
# so they work without any pip install step.
#
# Code help: https://github.com/botffy/polyskel
# ─────────────────────────────────────────────────────────────
# VENDORED (already included — no install required)
# ─────────────────────────────────────────────────────────────
#   py_straight_skeleton/   Straight-skeleton algorithm for hip roofs with holes
#   euclid3.py              2-D / 3-D geometry primitives (required by polyskel)
#   polyskel.py             Alternative straight-skeleton implementation (fallback)
#
# ─────────────────────────────────────────────────────────────
# OPTIONAL — install only if you want overhang buffering on roofs
# ─────────────────────────────────────────────────────────────
#
# Shapely provides precise polygon offset / buffer used by the
# Roof from Surface node when Overhang > 0.
# Without it the node falls back to a simple no-buffer path.
#
# Install into IngeTrazo's Python environment:
#   pip install shapely
#
# Or into the miniconda environment IngeTrazo uses:
#   conda install -c conda-forge shapely
#
shapely>=2.0
